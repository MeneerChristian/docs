# Indexes: Additional Assemblies
<Admonition type="note" title="">

* Index capabilities can be expanded by importing whole libraries 
  with useful classes and methods that can then be used in the index syntax.  
  **Additional Assemblies** make it very easy to import assemblies from:  
   * **NuGet**  
   * **Runtime**  
   * **Local file**  

* Indexes can be enhanced with capabilities like [machine learning image recognition](https://ayende.com/blog/192001-B/using-machine-learning-with-ravendb) 
  or [full text searching in Office files](https://ayende.com/blog/192385-A/ravendb-5-1-features-searching-in-office-documents).  

* This feature is similar to the [Additional Sources](../indexes/extending-indexes.mdx) feature, 
  that can be used to add methods and classes to an index in the form of a file or pure text.  
  These two features can be used together: an index's Additional Sources code has access to 
  all of the index's Additional Assemblies.  

* In this page:

## Syntax

Additional assemblies are defined using the `AdditionalAssembly` object.

<TabItem value="csharp" label="csharp">
<CodeBlock language="csharp">
{`public class AdditionalAssembly
\{
    public static AdditionalAssembly FromRuntime(string assemblyName, 
                                                 HashSet<string> usings = null);

    public static AdditionalAssembly FromPath(string assemblyPath, 
                                              HashSet<string> usings = null);

    public static AdditionalAssembly FromNuGet(string packageName, 
                                               string packageVersion, 
                                               string packageSourceUrl = null, 
                                               HashSet<string> usings = null);

    // Adds only 'using' directives, without referencing an assembly
    public static AdditionalAssembly OnlyUsings(HashSet<string> usings);
\}
`}
</CodeBlock>
</TabItem>

| Parameter | Type | Description |
| - | - | - |
| **assemblyName** | `string` | The name of an assembly to import from runtime |
| **assemblyPath** | `string` | Local path to an assembly |
| **packageName** | `string` | Name of a NuGet package to import |
| **packageVersion** | `string` | The version number of the NuGet package |
| **packageSourceUrl** | `string` | The URL of the package's original source - optional |
| **usings** | `HashSet<string>` | A set of namespaces to attach to the compiled index with `using` - optional for `FromRuntime`, `FromPath` and `FromNuGet`. In `OnlyUsings` it is required. |

* `FromRuntime`, `FromPath` and `FromNuGet` throw an `ArgumentException` when `assemblyName`, `assemblyPath`,  
  or `packageName` and `packageVersion` are null, empty, or white space.
* `OnlyUsings` throws an `ArgumentNullException` when `usings` is null or empty.

#### Properties of `AdditionalAssembly`

The `FromRuntime`, `FromPath`, `FromNuGet` and `OnlyUsings` factory methods are the only way to create an instance.  
The properties can be read, but not set:

| Property | Type | Description |
| - | - | - |
| **AssemblyName** | `string` | The runtime assembly name. Set by `FromRuntime`, otherwise `null`. |
| **AssemblyPath** | `string` | The local path of the assembly. Set by `FromPath`, otherwise `null`. |
| **PackageName** | `string` | The NuGet package name. Set by `FromNuGet`, otherwise `null`. |
| **PackageVersion** | `string` | The NuGet package version. Set by `FromNuGet`, otherwise `null`. |
| **PackageSourceUrl** | `string` | The NuGet package source URL. Set by `FromNuGet`, otherwise `null`. |
| **Usings** | `HashSet<string>` | The namespaces passed in `usings`. |

The `AdditionalAssembly`s are collected in `AdditionalAssemblies`, a property of 
`IndexDefinition`:  

<TabItem value="csharp" label="csharp">
<CodeBlock language="csharp">
{`public HashSet<AdditionalAssembly> AdditionalAssemblies;
`}
</CodeBlock>
</TabItem>



## Adding assemblies from an index class

* A class that derives from `AbstractIndexCreationTask<TDocument>` or `AbstractMultiMapIndexCreationTask<TReduceResult>`  
  can call the protected method `AddAssembly(AdditionalAssembly assembly)` in its constructor.  
  The assembly is added to the `AdditionalAssemblies` property of the task.  
  `AddAssembly` throws an `ArgumentNullException` when `assembly` is null.

* `AdditionalAssemblies` is also a public settable property of the task,  
  so a task can instead assign a whole `HashSet<AdditionalAssembly>`.

<TabItem value="add_assembly_index" label="add_assembly_index">
<CodeBlock language="csharp">
{`public class Companies_ByName : AbstractIndexCreationTask<Company>
\{
    public Companies_ByName()
    \{
        Map = companies => from company in companies
                          select new
                          \{
                              company.Name
                          \};

        AddAssembly(AdditionalAssembly.FromRuntime("System.Memory"));
        AddAssembly(AdditionalAssembly.FromNuGet("Microsoft.ML", "1.5.2"));
    \}
\}
`}
</CodeBlock>
</TabItem>

#### Adding only `using` directives

<TabItem value="only_usings" label="only_usings">
<CodeBlock language="csharp">
{`AdditionalAssemblies = \{
    AdditionalAssembly.OnlyUsings(new HashSet<string> \{ "System.Text" \})
\}
`}
</CodeBlock>
</TabItem>

## Examples

#### Basic Example

This index is able to use the method `GetFileName()` from the class `Path` 
because the namespace `System.IO` has been imported as an additional assembly. 
It takes a `string` file path and retrieves just the file name and extension.  

<TabItem value="simple_index" label="simple_index">
<CodeBlock language="csharp">
{`var runtimeindex = new IndexDefinition
\{
    Name = "Dog_Pictures",
    Maps = \{ @"
        from user in docs.Users
        let fileName = Path.GetFileName(user.ImagePath)
        where fileName = ""My_Dogs.jpeg""
        select new \{
            user.Name,
            fileName
        \}"
    \},
    AdditionalAssemblies = \{
        AdditionalAssembly.FromRuntime("System.IO")
    \}
\};
`}
</CodeBlock>
</TabItem>

#### Complex Example

This index uses a machine learning algorithm imported from NuGet that can 
recognize the contents of images and classify them with an appropriate tag. 
These tags are then stored in the index just like any other term.  

<TabItem value="complex_index" label="complex_index">
<CodeBlock language="csharp">
{`store.Maintenance.Send(new PutIndexesOperation(new IndexDefinition
\{
    Name = "Photographs/Tags",
    Maps =
    \{
        @"
        from p in docs.Photographs
        let photo = LoadAttachment(p, ""photo.png"")
        where photo != null
        let classified =  ImageClassifier.Classify(photo.GetContentAsStream())
        select new \{
            e.Name,
            Tag = classified.Where(x => x.Value > 0.75f).Select(x => x.Key),
            _ = classified.Select(x => CreateField(x.Key, x.Value))
        \}"
    \},
    AdditionalSources = new System.Collections.Generic.Dictionary<string, string>
    \{
        \{
            "ImageClassifier", 
            @"
            public static class ImageClassifier
            \{
                public static IDictionary<string, float> Classify(Stream s)
                \{
                    // returns a list of descriptors with a
                    // value between 0 and 1 of how well the
                    // image matches that descriptor.
                \}
            \}"
        \}

    \},
    AdditionalAssemblies =
    \{
        AdditionalAssembly.FromRuntime("System.Memory"),
        AdditionalAssembly.FromNuGet("System.Drawing.Common", "4.7.0"),
        AdditionalAssembly.FromNuGet("Microsoft.ML", "1.5.2")
    \}
\}));
`}
</CodeBlock>
</TabItem>

#### Pre-Release Packages

Additional assemblies are allowed to include pre-release packages.

<TabItem value="prerelease_assembly" label="prerelease_assembly">
<CodeBlock language="csharp">
{`AdditionalAssemblies = \{
    AdditionalAssembly.FromNuGet("FlexiMvvm.Common.PreRelease", "0.10.8-prerelease")
\}
`}
</CodeBlock>
</TabItem>
