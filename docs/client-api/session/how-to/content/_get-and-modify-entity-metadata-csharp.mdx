When a document is downloaded from the server, it contains various metadata information like ID or current change-vector. This information is stored in a session and is available for each entity using the `GetMetadataFor` method from the `Advanced` session operations.
## Get the Metadata

<TabItem value="get_metadata_1" label="get_metadata_1">
<CodeBlock language="csharp">
{`IMetadataDictionary GetMetadataFor<T>(T instance);
`}
</CodeBlock>
</TabItem>

| Parameters | | |
| ------------- | ------------- | ----- |
| **instance** | T | Instance of an entity for which metadata will be returned. |

| Return Value | |
| ------------- | ----- |
| IMetadataDictionary | Returns the metadata for the specified entity. Throws an exception if the `instance` is not tracked by the session. |

### Example

<TabItem value="get_metadata_2" label="get_metadata_2">
<CodeBlock language="csharp">
{`var employee = session.Load<Employee>("employees/1-A");
var metadata = session.Advanced.GetMetadataFor(employee);
`}
</CodeBlock>
</TabItem>


## Modify the Metadata
After getting the metadata from `session.Advanced.GetMetadataFor` you can modify it just like any other dictionary.
<Admonition type="note" title="">
Keys in the metadata that starting with @ are reserved for RavenDB use
</Admonition>

### Example I
<TabItem value="modify_metadata_1" label="modify_metadata_1">
<CodeBlock language="csharp">
{`var user = new User
\{
    Name = "Idan"
\};

session.Store(user);
var metadata = session.Advanced.GetMetadataFor(user);
metadata["Permissions"] = "ReadOnly";
session.SaveChanges();
`}
</CodeBlock>
</TabItem>

### Example II
<TabItem value="modify_metadata_2" label="modify_metadata_2">
<CodeBlock language="csharp">
{`var user = session.Load<User>("users/1-A");
var metadata = session.Advanced.GetMetadataFor(user);

metadata["Permissions"] = "ReadAndWrite";

session.SaveChanges();
`}
</CodeBlock>
</TabItem>

## Read Typed Metadata Values

Besides the indexer, `IMetadataDictionary` provides typed accessors that return a value converted to the requested type:

| Method | Return type | Description |
| ------------- | ------------- | ----- |
| **GetLong**(key) | `long` | Returns the value converted to `long`. |
| **GetBoolean**(key) | `bool` | Returns the value converted to `bool`. |
| **GetDouble**(key) | `double` | Returns the value converted to `double`. |
| **GetObject**(key) | `IMetadataDictionary` | Returns the value as a nested metadata object. |
| **GetObjects**(key) | `IMetadataDictionary[]` | Returns the value as an array of nested metadata objects. |

* `GetLong`, `GetBoolean` and `GetDouble` convert the stored value using invariant culture. A value that cannot be converted throws an exception.
* All accessors throw `KeyNotFoundException` when the key does not exist in the metadata.
* `GetObject` and `GetObjects` throw when the value is not a metadata object or an array of them, respectively.

```csharp
var user = session.Load<User>("users/1-A");
var metadata = session.Advanced.GetMetadataFor(user);

long loginCount = metadata.GetLong("LoginCount");
bool isVerified = metadata.GetBoolean("IsVerified");
double score = metadata.GetDouble("Score");

// Nested metadata: the value must be a metadata object or an array of them
IMetadataDictionary address = metadata.GetObject("Address");
IMetadataDictionary[] history = metadata.GetObjects("History");
```
