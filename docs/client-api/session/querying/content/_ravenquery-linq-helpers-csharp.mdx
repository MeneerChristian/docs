<Admonition type="note" title="">

* The static **`RavenQuery`** class provides helper methods for use **inside LINQ query expressions**.  
  Each call is translated by the client into RQL (or the JavaScript used by RQL) and executed on the server.

* These methods are **not** executable C# methods.  
  They only exist so the LINQ provider can recognize them.  
  Calling any of them directly, outside a LINQ query expression, throws a **`NotSupportedException`**.

* Add the following namespace to use `RavenQuery`:  
  `using Raven.Client.Documents.Queries;`

## Translation rules

* **Only inside LINQ queries**:  
  `RavenQuery` methods are recognized when they appear in a LINQ expression over `session.Query<T>()`.  
  They have no meaning on their own.

* **Direct calls throw**:  
  Every `RavenQuery` method body throws `NotSupportedException`.  
  If you need the same result in client code, use the session API instead, for example `session.Load<T>(id)` or `session.Advanced.GetMetadataFor(entity)`.

* **Scalar and document-level helpers**:  
  `Now`, `Today`, `CmpXchg`, `Load`, `Id`, `Metadata`, `LastModified`, `Counter`, `TimeSeries`, `Raw`, and `Include` are translated to RQL functions or query clauses on the server.

* **DocumentQuery alternatives**:  
  For `DocumentQuery` and `AsyncDocumentQuery`, use the `RavenDocumentQuery` helpers `Now` and `Today` instead of `RavenQuery.Now` and `RavenQuery.Today`.

## Raw

Signatures:

<CodeBlock language="csharp">
{`public static T Raw<T>(string js)
public static T Raw<T>(T path, string js)
`}
</CodeBlock>

* Injects a JavaScript expression into the query as-is.  
  The string is not validated by the client, so the expression must be valid for the server-side JavaScript engine.
* The single-argument form takes a **constant** string.
* The two-argument form appends the JavaScript to the translated `path` expression, as `path.js`.
* Use `Raw` only when RQL and LINQ cannot express what you need. See [JavaScript Engine](../../../../server/kb/javascript-engine.mdx).

<Admonition type="note" title="">

<Tabs groupId='languageSyntax'>
<TabItem value="Query" label="Query">
<CodeBlock language="csharp">
{`var employees = session.Query<Employee>()
    .Select(e => new
    {
        // Single-argument form: the JavaScript is used as the whole expression
        Date = RavenQuery.Raw<DateTime>("new Date(Date.parse(e.Birthday))"),
        // Two-argument form: 'e.FirstName' is followed by '.substr(0, 3)'
        Name = RavenQuery.Raw(e.FirstName, "substr(0, 3)")
    })
    .ToList();
`}
</CodeBlock>
</TabItem>
<TabItem value="RQL" label="RQL">
<CodeBlock language="sql">
{`from 'Employees' as e
select {
    Date: new Date(Date.parse(e.Birthday)),
    Name: e.FirstName.substr(0, 3)
}
`}
</CodeBlock>
</TabItem>
</Tabs>

</Admonition>

## TimeSeries

Signatures:

<CodeBlock language="csharp">
{`public static ITimeSeriesQueryable TimeSeries(string name)
public static ITimeSeriesQueryable TimeSeries(object documentInstance, string name)
public static ITimeSeriesQueryable TimeSeries(object documentInstance, string name, DateTime from, DateTime to)
public static ITimeSeriesQueryable<T> TimeSeries<T>(string name) where T : new()
public static ITimeSeriesQueryable<T> TimeSeries<T>(object documentInstance, string name) where T : new()
public static ITimeSeriesQueryable<T> TimeSeries<T>(object documentInstance, string name, DateTime from, DateTime to) where T : new()
`}
</CodeBlock>

* Starts a time series query on a document's time series, optionally limited to a date range.
* The chained calls (`Where`, `GroupBy`, `Select`, and so on) define the time series query.
* The generic overloads return entries typed as `T`.
* Translates to a `declare timeseries` function that the query calls for each document.

<Admonition type="note" title="">

<Tabs groupId='languageSyntax'>
<TabItem value="Query" label="Query">
<CodeBlock language="csharp">
{`var users = session.Query<User>()
    .Where(u => u.Age > 21)
    .Select(u => RavenQuery.TimeSeries(u, "Heartrate")
        .Where(ts => ts.Tag == "watches/fitbit")
        .GroupBy("1 month")
        .Select(g => new
        {
            Avg = g.Average(),
            Max = g.Max()
        })
        .ToList())
    .ToList();
`}
</CodeBlock>
</TabItem>
<TabItem value="RQL" label="RQL">
<CodeBlock language="sql">
{`// Simplified: the generated function body follows the chained calls
declare timeseries __timeSeriesQueryFunction0(u) {
    from u.Heartrate ... where Tag == 'watches/fitbit' group by '1 month' select ...
}
from 'Users' as u
where Age > 21
select __timeSeriesQueryFunction0(u)
`}
</CodeBlock>
</TabItem>
</Tabs>

</Admonition>

For the full time series syntax, see [time series query overview](../../../../document-extensions/timeseries/querying/overview-and-syntax.mdx).

## Now

Signatures:

<CodeBlock language="csharp">
{`public static DateTime Now()
public static DateTime Now(string offset)
`}
</CodeBlock>

* Returns the current UTC date and time on the server.
* The `offset` form adds an offset and floor-rounds the result to the smallest unit given.  
  Format: `[+|-]Ny[Nmo][Nd][Nh][Nm][Ns]`, with units in descending order, for example `"+1y6mo"`, `"-2hours30minutes"`, `"15d"`.
* Translates to `now()` or `now($parameter)`.

<Admonition type="note" title="">

<Tabs groupId='languageSyntax'>
<TabItem value="Query" label="Query">
<CodeBlock language="csharp">
{`var hires = session.Query<Employee>()
    .Where(e => e.HiredAt <= RavenQuery.Now())
    .ToList();
`}
</CodeBlock>
</TabItem>
<TabItem value="RQL" label="RQL">
<CodeBlock language="sql">
{`from 'Employees'
where HiredAt <= now()
`}
</CodeBlock>
</TabItem>
</Tabs>

</Admonition>

<Admonition type="note" title="">

<Tabs groupId='languageSyntax'>
<TabItem value="Query" label="Query">
<CodeBlock language="csharp">
{`var recentHires = session.Query<Employee>()
    // Server time minus 30 days, floor-rounded to the day
    .Where(e => e.HiredAt >= RavenQuery.Now("-30d"))

`}
</CodeBlock>
</TabItem>
<TabItem value="RQL" label="RQL">

## Include

Signature:

<CodeBlock language="csharp">
{`public static object Include<T>(Expression<Func<T, string>> path)
`}
</CodeBlock>

* Includes a related document in the query results, so it is loaded in the same request.
* The result must be assigned to the discard symbol `_`. Any other assignment throws an `InvalidOperationException`.
* When the path is a simple member access, the include is added as a regular `include` clause.  
  Other expressions are translated into the projection.

<Admonition type="note" title="">

<Tabs groupId='languageSyntax'>
<TabItem value="Query" label="Query">
<CodeBlock language="csharp">
{`var query = session.Query<Address>()
    .Select(a => new
    {
        // Include the State document referenced by StateId
        _ = RavenQuery.Include<Address>(x => x.StateId),
        a.StateId
    });

var addresses = query.ToList();
`}
</CodeBlock>
</TabItem>
<TabItem value="RQL" label="RQL">
<CodeBlock language="sql">
{`from 'Addresses'
select StateId
include StateId
`}
</CodeBlock>
</TabItem>
</Tabs>

</Admonition>
