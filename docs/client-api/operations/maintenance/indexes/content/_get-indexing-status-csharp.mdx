<Admonition type="note" title="">

* Use `GetIndexingStatusOperation` to get the indexing status of the database and of each of its indexes.

* The status is returned by the server node selected by the [client configuration](../../../../../client-api/configuration/load-balance/overview.mdx#client-logic-for-choosing-a-node).

* The `Status` values are defined by `IndexRunningStatus`:
    * `Running`, `Paused`, `Disabled`
    * `Pending` - used for rolling indexes.

* In this page:
    * [Get indexing status](../../../../../client-api/operations/maintenance/indexes/get-indexing-status.mdx#get-indexing-status)
    * [Syntax](../../../../../client-api/operations/maintenance/indexes/get-indexing-status.mdx#syntax)

</Admonition>
## Get indexing status

<Tabs groupId='languageSyntax'>
<TabItem value="Sync" label="Sync">
<CodeBlock language="csharp">
{`// Define the get indexing status operation
var getIndexingStatusOp = new GetIndexingStatusOperation();

// Execute the operation by passing it to Maintenance.Send
IndexingStatus indexingStatus = store.Maintenance.Send(getIndexingStatusOp);

// Database-level indexing status
var dbStatus = indexingStatus.Status;

// Status of each index
foreach (var index in indexingStatus.Indexes)
{
    var name = index.Name;
    var status = index.Status;
}
`}
</CodeBlock>
</TabItem>

<TabItem value="syntax_2" label="syntax_2">

    public IndexRunningStatus Status \{ get; set; \}   // Database-level indexing status
    public IndexStatus[] Indexes \{ get; set; \}

    public sealed class IndexStatus
    \{
        public string Name \{ get; set; \}
        public IndexRunningStatus Status \{ get; set; \}
    \}
\}

public enum IndexRunningStatus
\{
    Running,
    Paused,
    Disabled,
    Pending   // for rolling indexes
\}
`}
