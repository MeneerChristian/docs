<Admonition type="note" title="">

* Use `GetIndexPerformanceStatisticsOperation` to get the indexing performance history of **some or all indexes**.

* Each index returns a list of indexing runs (`IndexingPerformanceStats`). Each run includes a `Details` object (`IndexingPerformanceOperation`) with per-phase information.

* The statistics are returned by the server node selected by the [client configuration](../../../../../client-api/configuration/load-balance/overview.mdx#client-logic-for-choosing-a-node).

* In this page:
    * [Get performance statistics for all indexes](../../../../../client-api/operations/maintenance/indexes/get-index-performance-statistics.mdx#get-performance-statistics-for-all-indexes)
    * [Get performance statistics for specific indexes](../../../../../client-api/operations/maintenance/indexes/get-index-performance-statistics.mdx#get-performance-statistics-for-specific-indexes)
    * [Syntax](../../../../../client-api/operations/maintenance/indexes/get-index-performance-statistics.mdx#syntax)

</Admonition>
## Get performance statistics for all indexes

<Tabs groupId='languageSyntax'>
<TabItem value="Sync" label="Sync">
<CodeBlock language="csharp">
{`// Define the get index performance statistics operation
var getPerfStatsOp = new GetIndexPerformanceStatisticsOperation();

// Execute the operation by passing it to Maintenance.Send
IndexPerformanceStats[] perfStats = store.Maintenance.Send(getPerfStatsOp);

// Each entry holds the index name and its indexing runs
var indexName = perfStats[0].Name;
var runs = perfStats[0].Performance;
`}
</CodeBlock>
</TabItem>

#### The details classes

The `...Details` properties of `IndexingPerformanceOperation` are set on the nested operations (the `Operations` property) that record them, and are `null` on the others:

* `MapDetails` is set on the operation named `Map`.
* `ReferenceDetails` is set on the operation named `References`.
* `ReduceDetails` is set on the operation named `Reduce`, with the attempts, successes, errors and memory figures,  
  and on the reduce-trees operation, where it holds only `TreesReduceDetails`.
* `CleanupDetails` is set on the operations that clean up documents and time series.
* `LuceneMergeDetails` is set on the Lucene merge operation.
* `CommitDetails` is set on the storage commit operation.

| Class | Property | Description |
| - | - | - |
| `MapRunDetails` | **BatchCompleteReason** | The reason the map batch ended |
| | **ProcessPrivateMemory**, **ProcessWorkingSet** | The private memory and the working set of the server process, recorded for the batch |
| | **CurrentlyAllocated** | The allocations of the indexing thread, recorded for the batch |
| | **AllocationBudget** | The maximum memory allowed to the index, in bytes |
| `ReferenceRunDetails` | **ReferenceAttempts**, **ReferenceSuccesses**, **ReferenceErrors** | The number of attempts to index a reference (a document that is loaded by the index) and how many of them succeeded and failed |
| | **BatchCompleteReason** | The reason the references batch ended |
| | **ProcessPrivateMemory**, **ProcessWorkingSet**, **CurrentlyAllocated**, **AllocationBudget** | As in `MapRunDetails` |
| `ReduceRunDetails` | **ReduceAttempts**, **ReduceSuccesses**, **ReduceErrors** | The number of reduce attempts, and how many of them succeeded and failed |
| | **ProcessPrivateMemory**, **ProcessWorkingSet**, **CurrentlyAllocated** | As in `MapRunDetails` |
| | **TreesReduceDetails** | Details of the reduce trees, see below |
| `TreesReduceDetails` | **NumberOfModifiedLeafs**, **NumberOfModifiedBranches** | The number of leaf and branch pages of the reduce trees that were modified |
| | **NumberOfCompressedLeafs** | The number of leaf pages that were compressed |
| `CleanupRunDetails` | **DeleteSuccesses** | The number of tombstones that were processed successfully |
| | **BatchCompleteReason** | The reason the cleanup batch ended |
| `LuceneMergeDetails` | **TotalMergesCount** | The number of pending merges that were recorded |
| | **ExecutedMergesCount** | The number of merges that were executed |
| | **MergedFilesCount**, **MergedDocumentsCount** | The number of files and of documents that the executed merges covered |
| `StorageCommitDetails` | **NumberOfModifiedPages** | The number of pages modified by the commit |
| | **NumberOf4KbsWrittenToDisk** | The number of 4 KB blocks the commit wrote to disk |
