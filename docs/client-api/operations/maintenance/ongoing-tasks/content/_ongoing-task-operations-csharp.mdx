<Admonition type="note" title="">

* Once an ongoing task is created, it can be managed via the Client API [Operations](../../../../../client-api/operations/what-are-operations.mdx).   
  You can get task info, toggle the task state (enable, disable), or delete the task. 

* Ongoing tasks can also be managed via the [Tasks list view](../../../../../studio/database/tasks/ongoing-tasks/general-info.mdx#ongoing-tasks---view) in the Studio.

* In this page:
  * [Get ongoing task info](../../../../../client-api/operations/maintenance/ongoing-tasks/ongoing-task-operations.mdx#get-ongoing-task-info)

  * [Syntax](../../../../../client-api/operations/maintenance/ongoing-tasks/ongoing-task-operations.mdx#syntax)

## Get ongoing task info

For the examples in this article, let's create a simple external replication ongoing task:

<TabItem value="create_task" label="create_task">
<CodeBlock language="csharp">
{`// Define a simple External Replication task
var taskDefintion = new ExternalReplication
\{
    Name = "MyExtRepTask",
    ConnectionStringName = "MyConnectionStringName"
\};

// Deploy the task to the server
var taskOp = new UpdateExternalReplicationOperation(taskDefintion);
var sendResult = store.Maintenance.Send(taskOp);

// The task ID is available in the send result
var taskId = sendResult.TaskId;
`}
</CodeBlock>
</TabItem>
Use `GetOngoingTaskInfoOperation` to get information about an ongoing task.

<Tabs groupId='languageSyntax'>
<TabItem value="Sync" label="Sync">
<CodeBlock language="csharp">
{`// Define the get task operation, pass:
// * The ongoing task ID or the task name
// * The task type 
var getTaskInfoOp = new GetOngoingTaskInfoOperation(taskId, OngoingTaskType.Replication);

// Execute the operation by passing it to Maintenance.Send
var taskInfo = (OngoingTaskReplication)store.Maintenance.Send(getTaskInfoOp);

// Access the task info
var taskState = taskInfo.TaskState;
var taskDelayTime = taskInfo.DelayReplicationFor;
var destinationUrls= taskInfo.TopologyDiscoveryUrls;
// ...
`}
</CodeBlock>
</TabItem>
<TabItem value="Async" label="Async">
<CodeBlock language="csharp">
{`var getTaskInfoOp = new GetOngoingTaskInfoOperation(taskId, OngoingTaskType.Replication);
var taskInfo = (OngoingTaskReplication) await store.Maintenance.SendAsync(getTaskInfoOp);

var taskState = taskInfo.TaskState;
var taskDelayTime = taskInfo.DelayReplicationFor;
var destinationUrls= taskInfo.TopologyDiscoveryUrls;
// ...
`}
</CodeBlock>
</TabItem>
</Tabs>



## Delete ongoing task

Use `DeleteOngoingTaskOperation` to remove an ongoing task from the list of tasks assigned to the database.

<Tabs groupId='languageSyntax'>
<TabItem value="Sync" label="Sync">
<CodeBlock language="csharp">
{`// Define the delete task operation, pass:
// * The ongoing task ID
// * The task type 
var deleteTaskOp = new DeleteOngoingTaskOperation(taskId, OngoingTaskType.Replication);

// Execute the operation by passing it to Maintenance.Send
store.Maintenance.Send(deleteTaskOp);
`}
</CodeBlock>
</TabItem>
<TabItem value="Async" label="Async">
<CodeBlock language="csharp">
{`var deleteTaskOp = new DeleteOngoingTaskOperation(taskId, OngoingTaskType.Replication);
await store.Maintenance.SendAsync(deleteTaskOp);
`}
</CodeBlock>
</TabItem>
</Tabs>



## Toggle ongoing task state

Use `ToggleOngoingTaskStateOperation` to enable/disable the task state.

<Tabs groupId='languageSyntax'>
<TabItem value="Sync" label="Sync">
<CodeBlock language="csharp">
{`// Define the delete task operation, pass:
// * The ongoing task ID
// * The task type
// * A boolean value to enable/disable
var toggleTaskOp = new ToggleOngoingTaskStateOperation(taskId, OngoingTaskType.Replication, true);

// Execute the operation by passing it to Maintenance.Send
store.Maintenance.Send(toggleTaskOp);
`}
</CodeBlock>
</TabItem>
<TabItem value="Async" label="Async">
<CodeBlock language="csharp">
{`var toggleTaskOp = new ToggleOngoingTaskStateOperation(taskId, OngoingTaskType.Replication, true);
await store.Maintenance.SendAsync(toggleTaskOp);
`}
</CodeBlock>
</TabItem>
</Tabs>

* The `GetOngoingTaskInfoOperation(long taskId, OngoingTaskType type)` constructor throws an `ArgumentException`
  when `type` is `OngoingTaskType.PullReplicationAsHub`.
  Use `GetPullReplicationTasksInfoOperation` to get the info of a pull replication hub task.
* When the operation is sent with a `taskName` that is null or whitespace, the command it creates throws an `ArgumentException`.



## Ongoing task result types

`GetOngoingTaskInfoOperation` returns an `OngoingTask`.
Cast it to the class that matches the `type` you passed:

| `OngoingTaskType`       | Returned class                    |
|-------------------------|-----------------------------------|
| `Replication`           | `OngoingTaskReplication`          |
| `RavenEtl`              | `OngoingTaskRavenEtl`             |
| `SqlEtl`                | `OngoingTaskSqlEtl`               |
| `OlapEtl`               | `OngoingTaskOlapEtl`              |
| `ElasticSearchEtl`      | `OngoingTaskElasticSearchEtl`     |
| `QueueEtl`              | `OngoingTaskQueueEtl`             |
| `SnowflakeEtl`          | `OngoingTaskSnowflakeEtl`         |
| `Backup`                | `OngoingTaskBackup`               |
| `Subscription`          | `OngoingTaskSubscription`         |
| `PullReplicationAsSink` | `OngoingTaskPullReplicationAsSink`|
| `PullReplicationAsHub`  | `OngoingTaskPullReplicationAsHub` |
| `QueueSink`             | `OngoingTaskQueueSink`            |
| `CdcSink`               | `OngoingTaskCdcSink`              |
| `EmbeddingsGeneration`  | `EmbeddingsGeneration`            |
| `GenAi`                 | `GenAi`                           |

#### Properties shared by all task types

Every returned class derives from `OngoingTask`:

| Property               | Type                          | Description                                                          |
|------------------------|-------------------------------|----------------------------------------------------------------------|
| `TaskId`               | `long`                        | The task ID                                                          |
| `TaskType`             | `OngoingTaskType`             | The task type (set by the derived class, read-only for callers)      |
| `TaskName`             | `string`                      | The task name                                                        |
| `TaskState`            | `OngoingTaskState`            | `None`, `Enabled`, `Disabled` or `PartiallyEnabled`                  |
| `TaskConnectionStatus` | `OngoingTaskConnectionStatus` | `None`, `Active`, `NotActive`, `Reconnect` or `NotOnThisNode`        |
| `ResponsibleNode`      | `NodeId`                      | The node responsible for the task. `NodeId` has the public fields `NodeTag`, `NodeUrl` and `ResponsibleNode` |
| `MentorNode`           | `string`                      | The mentor node tag of the task                                      |
| `PinToMentorNode`      | `bool`                        | Whether the task is pinned to the mentor node                        |
| `Error`                | `string`                      | An error message about the task                                      |

#### Task-specific properties

| Class                              | Additional properties |
|------------------------------------|-----------------------|
| `OngoingTaskReplication`           | `FromToString` (`string`), `DestinationUrl` (`string`), `TopologyDiscoveryUrls` (`string[]`), `DestinationDatabase` (`string`), `ConnectionStringName` (`string`), `DelayReplicationFor` (`TimeSpan`), `LastAcceptedChangeVectorFromDestination` (`string`), `SourceDatabaseChangeVector` (`string`), `LastSentEtag` (`long`), `LastDatabaseEtag` (`long`) |
| `OngoingTaskPullReplicationAsHub`  | `FromToString`, `DestinationUrl`, `DestinationDatabase` (`string`), `DelayReplicationFor` (`TimeSpan`), `HandlerId` (`string`), `LastAcceptedChangeVectorFromDestination`, `SourceDatabaseChangeVector` (`string`), `LastSentEtag`, `LastDatabaseEtag` (`long`) |
| `OngoingTaskPullReplicationAsSink` | `HubName` (`string`), `Mode` (`PullReplicationMode`: `None`, `HubToSink`, `SinkToHub`), `DestinationUrl` (`string`), `TopologyDiscoveryUrls` (`string[]`), `DestinationDatabase` (`string`), `ConnectionStringName` (`string`), `CertificatePublicKey` (`string`), `AccessName` (`string`), `AllowedHubToSinkPaths` (`string[]`), `AllowedSinkToHubPaths` (`string[]`), `HubCursor` (`string`), `SinkCursor` (`string`) |
| `OngoingTaskRavenEtl`              | `DestinationUrl`, `DestinationDatabase`, `ConnectionStringName` (`string`), `TopologyDiscoveryUrls` (`string[]`), `Configuration` (`RavenEtlConfiguration`) |

| `OngoingTaskOlapEtl`               | `ConnectionStringName`, `Destination` (`string`), `Configuration` (`OlapEtlConfiguration`) |
| `OngoingTaskElasticSearchEtl`      | `ConnectionStringName` (`string`), `NodesUrls` (`string[]`), `Configuration` (`ElasticSearchEtlConfiguration`) |
| `OngoingTaskQueueEtl`              | `BrokerType` (`QueueBrokerType`), `ConnectionStringName`, `Url` (`string`), `Configuration` (`QueueEtlConfiguration`) |
| `OngoingTaskSnowflakeEtl`          | `ConnectionStringName`, `ConnectionString` (`string`), `Configuration` (`SnowflakeEtlConfiguration`) |
| `OngoingTaskQueueSink`             | `BrokerType` (`QueueBrokerType`), `ConnectionStringName`, `Url` (`string`), `Configuration` (`QueueSinkConfiguration`) |
| `OngoingTaskSubscription`          | `Query`, `SubscriptionName` (`string`), `SubscriptionId` (`long`), `ArchivedDataProcessingBehavior` (`ArchivedDataProcessingBehavior?`), `ChangeVectorForNextBatchStartingPoint` (`string`), `ChangeVectorForNextBatchStartingPointPerShard` (`Dictionary<string, string>`), `LastBatchAckTime`, `LastClientConnectionTime` (`DateTime?`), `Disabled` (`bool`) |
| `OngoingTaskBackup`                | `BackupType` (`BackupType`: `Backup`, `Snapshot`), `BackupDestinations` (`List<string>`), `LastFullBackup`, `LastIncrementalBackup` (`DateTime?`), `OnGoingBackup` (`RunningBackup`), `NextBackup` (`NextBackup`), `RetentionPolicy` (`RetentionPolicy`), `IsEncrypted` (`bool`), `LastExecutingNodeTag`, `FullBackupFrequency`, `IncrementalBackupFrequency` (`string`), `BackupUploadMode` (`BackupUploadMode`: `Default`, `DirectUpload`), `HasCloudBackup` (`bool`) |
| `OngoingTaskCdcSink`               | `Configuration` (`CdcSinkConfiguration`), `ConnectionStringName`, `FactoryName` (`string`), `LastBatchTime`, `LastActivityTime` (`DateTime?`), `LastCheckpoint` (`string`), `SecondsSinceLastBatch`, `SecondsSinceLastActivity` (`double?`), `HealthIssue` (`string`) |
| `EmbeddingsGeneration`             | `ConnectionStringName` (`string`), `Configuration` (`EmbeddingsGenerationConfiguration`) |
| `GenAi`                            | `ConnectionStringName` (`string`), `Configuration` (`GenAiConfiguration`), `ChangeVector` (`string`) |

`NextBackup` has the properties `TimeSpan` (`TimeSpan`), `DateTime` (`DateTime`), `IsFull` (`bool`) and `OriginalBackupTime` (`DateTime?`).
`RunningBackup` has the properties `StartTime` (`DateTime?`), `IsFull` (`bool`) and `RunningBackupTaskId` (`long`).

`DeleteOngoingTaskOperation` and `ToggleOngoingTaskStateOperation` return a `ModifyOngoingTaskResult`
with `TaskId` (`long`) and the public fields `RaftCommandIndex` (`long`) and `ResponsibleNode` (`string`).
