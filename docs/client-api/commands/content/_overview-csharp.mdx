<Admonition type="note" title="">

* RavenDB's Client API is structured in layers.  
  At the highest layer, you interact with the [document store](../../../client-api/what-is-a-document-store.mdx) and the [document session](../../../client-api/session/what-is-a-session-and-how-does-it-work.mdx),  
  which handle most common database tasks like loading, saving, and querying documents.

* Beneath this high-level interface are Operations and Commands:

    * **Operations**:

        * Operations provide management functionality outside the session's context,  
          like creating a database, performing bulk actions, or managing server-wide configurations.

        * Learn more about Operations in [what are Operations](../../../client-api/operations/what-are-operations.mdx).

    * **Commands**:

        * All high-level methods and Operations are built on top of Commands.  
          Commands form the lowest-level operations that directly communicate with the server.

        * For example, a session’s _Load_ method translates internally to a _LoadOperation_,  
          which ultimately relies on a _GetDocumentsCommand_ to fetch data from the server.

        * Commands are responsible for sending the appropriate request to the server using a `Request Executor`,  
          and parsing the server's response.

        * All commands can be executed using either the [Store's _Request Executor_](../../../client-api/commands/overview.mdx#execute-command---using-the-store)
          or the [Session's _Request Executor_](../../../client-api/commands/overview.mdx#execute-command---using-the-session),  
          regardless of whether the command is session-related or not.

* This layered structure lets you work at any level, depending on your needs.

* In this page:
    * [Execute command - using the Store Request Executor](../../../client-api/commands/overview.mdx#execute-command---using-the-store-request-executor)
    * [Execute command - using the Session Request Executor](../../../client-api/commands/overview.mdx#execute-command---using-the-session-request-executor)
    * [Available commands](../../../client-api/commands/overview.mdx#available-commands)
    * [Syntax](../../../client-api/commands/overview.mdx#syntax)

</Admonition>
## Execute command - using the Store Request Executor

This example shows how to execute the low-level `CreateSubscriptionCommand` via the **Store**.  
(For examples of creating a subscription using higher-level methods, see [subscription creation examples](../../../client-api/data-subscriptions/creation/examples.mdx)).

<Tabs groupId='languageSyntax'>
<TabItem value="Execute_command" label="Execute_command">
<CodeBlock language="csharp">
{`// Using the store object
using (var store = new DocumentStore())
// Allocate a context from the store's context pool for executing the command
using (store.GetRequestExecutor().ContextPool.AllocateOperationContext(out var context))
{
    // Define a command
    var cmd = new CreateSubscriptionCommand(store.Conventions,
        new SubscriptionCreationOptions()
    {
        Name = "Orders subscription",
        Query = "from Orders" 
    });
    
    // Call 'Execute' on the store's Request Executor to send the command to the server,
    // pass the command and the store context.
    store.GetRequestExecutor().Execute(cmd, context);
}
`}
</CodeBlock>
</TabItem>
<TabItem value="Execute_command_async" label="Execute_command_async">
<CodeBlock language="csharp">
{`// Using the store object
using (var store = new DocumentStore())
// Allocate a context from the store's context pool for executing the command
using (store.GetRequestExecutor().ContextPool.AllocateOperationContext(out var context))
{

        Query = "from Orders"

    // pass the command and the store context.
    await store.GetRequestExecutor().ExecuteAsync(cmd, context);
}

## Execute command - using the Session Request Executor

This example shows how to execute the low-level `GetDocumentsCommand` via the **Session**.  
(For loading a document using higher-level methods, see [loading entities](../../../client-api/session/loading-entities.mdx)).

<Tabs groupId='languageSyntax'>
<TabItem value="Execute_command" label="Execute_command">
<CodeBlock language="csharp">
{`// Using the session
using (var session = store.OpenSession())
{
    // Define a command
    var cmd = new GetDocumentsCommand(store.Conventions, "orders/1-A", null, false);

    // Call 'Execute' on the session's Request Executor to send the command to the server
    // Pass the command and the 'Session.Advanced.Context'
    session.Advanced.RequestExecutor.Execute(cmd, session.Advanced.Context);
    
    // Access the results
    var blittable = (BlittableJsonReaderObject)cmd.Result.Results[0];

    // Deserialize the blittable JSON into your typed object
    var order = session.Advanced.JsonConverter.FromBlittable<Order>(ref blittable,
        "orders/1-A", false);

    // Now you have a strongly-typed Order object that can be accessed
    var orderedAt = order.OrderedAt;
}
`}
</CodeBlock>
</TabItem>
<TabItem value="Execute_command_async" label="Execute_command_async">
<CodeBlock language="csharp">
{`// Using the session
using (var asyncSession = store.OpenAsyncSession())
{
    // Define a command
    var cmd = new GetDocumentsCommand(store.Conventions, "orders/1-A", null, false);
    
    // Call 'ExecuteAsync' on the session's Request Executor to send the command to the server
    // Pass the command and the 'Session.Advanced.Context'
    await asyncSession.Advanced.RequestExecutor.ExecuteAsync(cmd, 
        asyncSession.Advanced.Context);
    
    // Access the results
    var blittable = (BlittableJsonReaderObject)cmd.Result.Results[0];

    // Deserialize the blittable JSON into your typed object
    var order = asyncSession.Advanced.JsonConverter.FromBlittable<Order>(ref blittable,
        "orders/1-A", true);

    // Now you have a strongly-typed Order object that can be accessed
    var orderedAt = order.OrderedAt;
}
`}
</CodeBlock>
</TabItem>
</Tabs>

* Note that the transaction created for the HTTP request when executing the command  
  is separate from the transaction initiated by the session's [SaveChanges](../../../client-api/session/saving-changes.mdx) method,  
  even if both are called within the same code block.

* Learn more about transactions in RavenDB in [Transaction support](../../../client-api/faq/transaction-support.mdx).

## Writing a custom command

You can execute your own request by deriving from `RavenCommand<TResult>` (namespace `Raven.Client.Http`)
and passing the command to the request executor as shown above.
Derive from the non-generic `RavenCommand` when the command has no typed result; its `Result` is an `object`,
and its `IsReadRequest` is `false`.

A command must implement `IsReadRequest` and `CreateRequest`.
When the response is a JSON object, it must also override `SetResponse`.

<TabItem value="custom_command" label="custom_command">
<CodeBlock language="csharp">
{`public sealed class GetDatabaseIdCommand : RavenCommand<string>
\{
    public override bool IsReadRequest => true;

    public override HttpRequestMessage CreateRequest(JsonOperationContext ctx, ServerNode node, out string url)
    \{
        url = $"\{node.Url\}/databases/\{node.Database\}/stats";
        return new HttpRequestMessage
        \{
            Method = HttpMethod.Get
        \};
    \}

    public override void SetResponse(JsonOperationContext context, BlittableJsonReaderObject response, bool fromCache)
    \{
        response.TryGet("DatabaseId", out string databaseId);
        Result = databaseId;
    \}
\}

using (store.GetRequestExecutor().ContextPool.AllocateOperationContext(out var context))
\{
    var cmd = new GetDatabaseIdCommand();
    store.GetRequestExecutor().Execute(cmd, context);
    string databaseId = cmd.Result;
\}
`}
</CodeBlock>
</TabItem>

#### Members of `RavenCommand<TResult>`

| Member | Type | Description |
|---|---|---|
| **IsReadRequest** | `bool` (abstract) | Whether the command only reads. |
| **CreateRequest**(ctx, node, out url) | `HttpRequestMessage` (abstract) | Creates the HTTP request and returns the URL for the given node. |
| **SetResponse**(context, response, fromCache) | `void` (virtual) | Receives the JSON response when `ResponseType` is `Object`. The default implementation throws an `InvalidDataException` when `ResponseType` is `Empty` or `Raw`, and otherwise an `InvalidOperationException` that asks you to override the method. |
| **SetResponseRaw**(response, stream, context) | `void` (virtual) | Receives the response stream when `ResponseType` is `Raw`. The default implementation throws a `NotSupportedException`. `SetResponseRawAsync` calls it by default. |
| **ProcessResponse**(context, cache, response, url) | `Task<ResponseDisposeHandling>` (virtual) | Reads the response. It returns without reading the body when `ResponseType` is `Empty` or the status is 204 (No Content). For `Object`, it skips an empty body, otherwise reads the JSON, caches it when the command can cache and the response has an ETag header, and calls `SetResponse` with `fromCache: false`. For `Raw`, it calls `SetResponseRawAsync` and does not cache. |
| **OnBeforeRequest**(request) | `void` (virtual) | Called with the HTTP request before it is sent. The default does nothing. |
| **OnResponseFailure**(response) | `void` (virtual) | Called with an unsuccessful response. The default does nothing. |
| **Result** | `TResult` (field) | The command result. |
| **ResponseType** | `RavenCommandResponseType` | `Empty`, `Object` or `Raw`. Default: `Object`. |
| **Timeout** | `TimeSpan?` | A timeout for the command. Default: `null`. |
| **CanCache** | `bool` | Whether the response may be cached. Default: `true`. |
| **CanCacheAggressively** | `bool` | Whether the response may be cached aggressively. Default: `true`. |
| **SelectedNodeTag** | `string` | The tag of the node to send the command to. Default: `null`. |
| **CancellationToken** | `CancellationToken` (field) | Default: `CancellationToken.None`. |
| **StatusCode** | `HttpStatusCode` (field) | The status code of the response. |
| **FailedNodes** | `Dictionary<ServerNode, Exception>` (field) | The nodes the command failed on, with their exceptions. |
| **NumberOfAttempts** | `int` | The number of attempts made for the command. Its setter is internal. |

The setters of `ResponseType`, `Timeout`, `CanCache`, `CanCacheAggressively` and `SelectedNodeTag` are `protected internal`, so a derived command sets them (for example in its constructor).

Related types:

* `RavenCommandResponseType`: `Empty`, `Object`, `Raw`.
* `ResponseDisposeHandling`: `Manually`, `Automatic`. It is the return value of `ProcessResponse`; the default implementation returns `Automatic`.
* `IRaftCommand`: a command can implement it. It has the property `string RaftUniqueRequestId { get; }`.
* `IBroadcast`: a command can implement it. It has the method `IBroadcast PrepareToBroadcast(JsonOperationContext context, DocumentConventions conventions)`.


## Request executor members

`store.GetRequestExecutor()` returns a `RequestExecutor` (namespace `Raven.Client.Http`).
Besides `Execute` and `ExecuteAsync`, it exposes these public members:

| Member | Type | Description |
|---|---|---|
| **Url** | `string` | The URL of the preferred node. `null` when the executor has no node selector yet. |
| **Topology** | `Topology` | The current topology (`null` when there is no node selector). |
| **TopologyNodes** | `IReadOnlyList<ServerNode>` | The nodes of the current topology. |
| **TopologyEtag** | `long` | The etag of the topology. |
| **ClientConfigurationEtag** | `long` | The etag of the client configuration that was last applied. |
| **NumberOfServerRequests** | `long` (field) | Incremented for each request that is sent to a server. |
| **Conventions** | `DocumentConventions` (field) | The conventions the executor uses. |
| **Certificate** | `X509Certificate2` | The client certificate. |
| **ContextPool** | `JsonContextPool` (field) | The pool used to allocate operation contexts. |
| **Cache** | `HttpCache` (field) | The HTTP cache of the executor. |
| **AggressiveCaching** | `AsyncLocal<AggressiveCacheOptions>` (field) | Holds the aggressive caching options of the current async context. |
| **DefaultTimeout** | `TimeSpan?` | The timeout for commands that do not set their own. It is initialized from `Conventions.RequestTimeout`. The setter throws an `InvalidOperationException` when the value is larger than `Conventions.GlobalHttpClientTimeout`, unless that timeout is infinite. |
| **ChooseNodeForRequest**(cmd, sessionInfo) | `(int? CurrentIndex, ServerNode CurrentNode)` | Chooses the node for a command. When the command has a `SelectedNodeTag`, it returns the promotable node with that tag, or the requested node. |
| **GetRequestedNode**(nodeTag) | `Task<(int Index, ServerNode Node)>` | Returns the node with the given tag. Throws `RequestedNodeUnavailableException` when the tag is not in the topology. |
| **GetPreferredNode**() | `Task<(int Index, ServerNode Node)>` | Returns the preferred node. |
| **GetNodeBySessionId**(sessionId) | `Task<(int Index, ServerNode Node)>` | Returns the node that is selected for the session ID. Throws `AllTopologyNodesDownException` when the topology has no nodes. |
| **GetFastestNode**() | `Task<(int Index, ServerNode Node)>` | Returns the fastest node. |
| **UpdateTopologyAsync**(parameters) | `Task<bool>` | Fetches the topology from `parameters.Node` and updates the executor with it. Returns `false` when topology updates are disabled, the executor is disposed, or the update lock is not acquired within `parameters.TimeoutInMs`. Throws `ArgumentNullException` when `parameters` is `null`. |
| **ClientConfigurationChanged** | event | Raised with the Raft command index and the `ClientConfiguration` after the executor applied a client configuration it fetched. |
| **OnTopologyUpdated** | event | Raised with `TopologyUpdatedEventArgs` after the topology was updated. |

`UpdateTopologyParameters` (nested in `RequestExecutor`) has these members:

| Member | Type | Default | Description |
|---|---|---|---|
| **Node** | `ServerNode` | (constructor argument) | The node to fetch the topology from. The constructor throws `ArgumentNullException` for `null`. |
| **TimeoutInMs** | `int` | `15000` | How long to wait for the topology update lock. |
| **ForceUpdate** | `bool` | `false` | Passed to the node selector update. |
| **DebugTag** | `string` | `null` | A tag that is sent with the topology request and passed to `OnTopologyUpdated`. |
| **ApplicationIdentifier** | `Guid?` | `null` | Sent with the topology request only when `Conventions.SendApplicationIdentifier` is `true`. |


## MultiGetCommand

`MultiGetCommand` (namespace `Raven.Client.Documents.Commands.MultiGet`) sends several `GET` requests to the database in one HTTP request.
It posts the requests to the database's `/multi_get` endpoint and returns a `List<GetResponse>` in `Result`.
Its constructor throws an `ArgumentNullException` when the request executor, the executor's `Cache`, or the list of requests is `null`.
The command implements `IDisposable`.

<TabItem value="multi_get" label="multi_get">
<CodeBlock language="csharp">
{`var requests = new List<GetRequest>
\{
    new GetRequest
    \{
        Url = "/docs",
        Query = "?id=users/1-A",
        Method = HttpMethod.Get
    \},
    new GetRequest
    \{
        Url = "/stats",
        Method = HttpMethod.Get
    \}
\};

var requestExecutor = store.GetRequestExecutor();
using (requestExecutor.ContextPool.AllocateOperationContext(out var context))
using (var cmd = new MultiGetCommand(requestExecutor, requests))
\{
    requestExecutor.Execute(cmd, context);

    foreach (GetResponse response in cmd.Result)
    \{
        if (response.RequestHasErrors())
            continue;

        BlittableJsonReaderBase result = response.Result;
    \}
\}
`}
</CodeBlock>
</TabItem>

#### `GetRequest`

| Member | Type | Default | Description |
|---|---|---|---|
| **Url** | `string` | `null` | The relative URL of the request |
| **Query** | `string` | `null` | The query string, for example `?pageStart=10&pageSize=20`. A leading `?` is added when it is missing. |
| **UrlAndQuery** | `string` (read-only) | | `Url` followed by `Query`, or `Url` alone when `Query` is `null` |
| **Method** | `HttpMethod` | `null` | The HTTP method |
| **Headers** | `IDictionary<string, string>` | an empty dictionary with case-insensitive keys | The request headers |
| **CanCacheAggressively** | `bool` | `true` | Whether the response may be cached aggressively |
| **Content** | `GetRequest.IContent` | `null` | The request body. `IContent` has the method `void WriteContent(AbstractBlittableJsonTextWriter writer, JsonOperationContext context)`. |

#### `GetResponse`

| Member | Type | Description |
|---|---|---|
| **Result** | `BlittableJsonReaderBase` | The response body as JSON |
| **Headers** | `Dictionary<string, string>` | The response headers (the dictionary is created with case-insensitive keys) |
| **StatusCode** | `HttpStatusCode` | The response status code |
| **ForceRetry** | `bool` | Whether the request should be retried |
| **RequestHasErrors**() | `bool` | `false` when the status code is 0 (aggressively cached), 200, 201, 203, 204, 304 or 404, and `true` otherwise |
